# Gabarits d'import de référentiel

`referentiel-modele.csv` est un **gabarit vide** : trois lignes d'exemple
inventées, à remplacer entièrement. Il donne les colonnes attendues et leur
ordre.

Le contenu des référentiels sous droits (ISO 27001, CIS Controls) **ne doit pas
être commité dans ce dépôt**. Ce répertoire ne contient que des gabarits.

Format complet : `docs/format_import_referentiel.md`.
